# Ai-books — AI Book Studio

Modulare, langfristig gepflegte Buchproduktion mit KI-Unterstützung, deterministischen Generatoren und menschlichen Veröffentlichungsfreigaben.

**Einstieg für Menschen und Agenten:** [AGENTS.md](AGENTS.md) → [gehirn/00-START-HIER.md](gehirn/00-START-HIER.md).

Status: Grundlagen-/MVP-Aufbau. Keine fertige veröffentlichungsreife KDP-Automatik, kein selbstständiger Amazon-Upload.

Grundsätze: Nachfrage vor Produktion; Qualität vor Menge; zeitlose Inhalte bevorzugen; Open Source und niedrige Kosten; keine ungeprüfte Veröffentlichung; reproduzierbare Dateien und Fehlerprotokolle.
